# forkline/cli

Release artifacts, installers and npm packages for the **Forkline CLI** (`forkline`).

The source code is private; this repository is the public distribution mirror:

- **Releases**: pre-built binaries for macOS (arm64/x64), Linux (gnu/musl, arm64/x64) and Windows (arm64/x64)
- **npm**: `@forkline/cli` wrapper + per-platform packages (coming soon)
- **install.sh**: curl-able installer (coming soon)

## Install

For now, download the archive for your platform from the [Releases](https://github.com/forkline/cli/releases) page, verify the SHA256 checksum, extract and put `forkline` on your PATH.

See https://forkline.dev for product documentation.
